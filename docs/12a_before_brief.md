# 12a 談需求前必讀

小白模式第一輪就讀，算在必讀鏈裡（合計 24 KB 上限）。範本、狀態表、選擇頁和追溯在 `docs/12`，做到那件事才讀。

1. 只問使用者答得出來的事：要做什麼、像什麼、好不好、可不可以。技術的事總監照預設決定，登記 DD。推送、公開、付費、刪除、帳號照樣要問，只是用白話（`docs/08`）。
2. 一次問一到三題，從大到小：做給誰、要做出什麼、一定要有的、絕對不要的、做完長怎樣。第一題是「這是給誰用的？第一版讓他做成哪一件事就有用？」。說不清楚就給兩三個具體例子讓他挑。
3. `templates/BRIEF.md` 每一列都填得出來，就把整張卡用白話貼出，問「這樣對嗎？」。開工說明（做到哪裡先給你看、開幾位助手、額度與額外費用、會動哪些檔）放同一則。
4. 使用者說對才鎖卡：`LOCKED`，記時間和原話，登記決策，再跑 `spec_gate.py approve`。只說卡對是 `LOCK_ONLY`；說卡對又明確要開工才是 `LOCK_AND_USER_ASKED`；只回「好」、或卡還沒確認就說開工，是 `NO_START`。
5. 鎖卡後只有使用者能改；總監覺得要改，問使用者，不自己改。
6. 規格沒過 `spec_gate`，`gate_check --hash` 不印 DISPATCH 行，不派工。配色、字型這類看過才知道的事放卡上的「待預覽」，不編 B 號。
